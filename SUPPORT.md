# Support / サポート

## English

RepoShout is maintained by one person as a side project. There is no service-level agreement and no guaranteed response time.

### Where to ask

**[GitHub Issues](https://github.com/Driedsandwich/reposhout/issues)** — the only channel. Issues are open to anyone with a GitHub account; no interaction limits are set (checked 2026-08-05).

Please do not use issues for suspected security problems. See [SECURITY.md](SECURITY.md) instead.

### What helps

Include as much of this as applies:

- The page you were on — the URL, or just its shape (`/owner/repo/pull/123`) if the repository is private
- What you expected and what happened
- Whether you were signed in to GitHub
- Browser and version (`chrome://version`)
- RepoShout's version (`chrome://extensions`, or the badge in the README)

If the Share button is missing, it is worth checking first whether the window is wide enough — GitHub hides its own Fork/Star row on narrow windows, and RepoShout deliberately follows that. The toolbar icon and <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> work regardless.

### What is out of scope

- GitHub Enterprise and Gist — not supported by design
- Browsers other than Chrome and Chromium-based ones
- Posting on your behalf — the extension will never do this, and requests to add it will be declined

## 日本語

RepoShout は個人が趣味で作っているものです。対応期限の保証はありません。

### 相談先

**[GitHub Issues](https://github.com/Driedsandwich/reposhout/issues)** の1本だけです。GitHubアカウントがあれば誰でも立てられます（制限は設定していません。2026-08-05確認）。

セキュリティ上の問題と思われるものは Issue に書かないでください。[SECURITY.md](SECURITY.md) を参照してください。

### 書いてあると助かること

- どのページだったか（URL、非公開リポジトリなら `/owner/repo/pull/123` のような形だけでも構いません）
- 期待した動作と、実際に起きたこと
- GitHubにログインしていたかどうか
- ブラウザとそのバージョン（`chrome://version`）
- RepoShout のバージョン（`chrome://extensions` か、READMEのバッジ）

Share ボタンが出ないときは、まずウィンドウの幅を確認してください。GitHub自身が細い幅では Fork / Star の行を隠す作りで、RepoShout はそれに合わせています。ツールバーアイコンと <kbd>Option</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> は幅に関係なく使えます。

### 対象外

- GitHub Enterprise と Gist（設計上の対象外）
- Chrome / Chromium 系以外のブラウザ
- 自動投稿。この拡張が代わりに投稿することはなく、その追加要望はお断りします
